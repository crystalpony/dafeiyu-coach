# 产品升级计划 · 1.4.0 舞台版

> 对标附件已收到：一张手机桌面宠物菜单截图（小红书视频，产品名未在画面出现）。可见菜单有 13 个顶层类目：待机、转向、拖拽、点击回应、移动、小动作、玩耍、吃什么、时节、文字、余额档位、碎碎念、工作状态；其中「时节」展开 15 个节日动作。以下只按画面可见能力对比，不推断不可见功能。

## 1. 目标

把小黑的“跟着唱歌”从一个静态 `sing` 循环，升级成可自动编排的小型舞台表演，同时不改变角色造型、不新增违反物理的肢体、不牺牲帧率与切换手感。

## 3. 1.4.0 交付范围

1. **唱歌变体**
   - `sing`：2 拍身体律动、头部左右摆、尾巴摆动、音符。
   - `sing_mic`：尾巴从左侧卷起，绕住麦克风手柄；麦克风为平涂贴图，不新增肢体。
   - `sing_hat`：薄荷绿街舞帽，帽檐、缝线、金色扣；身体弹跳与尾巴同步。
   - `sing_tail`：坐直、抬高身体与尾巴，尾巴大幅摆动。
2. **自动编排**
   - 固定风格：自动 / 只律动 / 尾巴麦克风 / 街舞帽 / 坐直摇尾。
   - 自动模式：每 8–16 秒偶发切到一种特别动作；同曲不连续重复同一特别动作。
   - 所有切换使用 0.36s 交叉淡化，不硬切。
   - 「试唱一段（20 秒）」无需音乐监听即可预览；试唱/音乐超时自动回 idle。
3. **喵喵叫**
   - 新增 `meowEnabled`，默认开；仅控制待机随机喵，菜单「喵一声 / 喵两声」始终可手动触发。
   - 「喵两声」复用同一段 36 帧动作连播，不新增素材；新增 CC0 猫叫音效与独立音效开关；修复一次性动作回调后自动回 idle 会顶掉第二段的问题。
4. **菜单信息架构**
   - 顶层 7 组：互动与专注 / 小黑日常 / 唱歌 / 陪伴与指导 / 形象 / 小黑设置 / 显示与尺寸。
   - 小黑日常：小动作、玩耍、吃什么、时节、移动、说句话、碎碎念、工作状态；对标截图中的日常类目基本覆盖，同时保留更干净的 Agent/音乐/形象分组。
5. **接口**
   - `dafeiyu config --meow on|off`
   - `dafeiyu config --sing-style auto|sway|mic|hat|tail`
   - `status` 暴露 `meowEnabled` / `singStyle` / `singVariants` / `singVariant`。

## 4. 超越点

- 不只是“会唱歌”，而是**有编排的唱歌**：自动模式让同一首歌里出现麦克风、帽子、摇尾等段落，避免循环疲劳。
- 所有表演都建立在**同一张手绘底图 + 平涂道具**上，不换脸、不换身体、不拼接来源不明的素材。
- 自动切换有**冷却与去重**，不是每句歌词都闪一下。
- 喵喵叫和唱歌都能单独关，菜单与 CLI 双入口。
- 每个变体都进入 QA 与审计，不只做演示图。

## 5. 后续路线

- 1.5：按歌曲段落（主歌/副歌）编排唱歌动作；歌词节拍驱动的尾巴/耳朵微动；更多不改变轮廓的道具（墨镜、应援棒）。
- 1.6：用户自定义唱歌花样序列；每首歌记住上次编排。
- 2.0：角色素材包协议，允许用户导入自己的手绘角色与动作清单。
